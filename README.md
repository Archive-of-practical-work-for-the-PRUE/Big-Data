# Кредитный скоринг: Random Forest и Gradient Boosting

Учебный проект по бинарной классификации заёмщиков: предсказание вероятности дефолта (`TARGET = 1`) по данным банка.

## Данные

- `scoring case.xlsx` — клиенты и кредитные истории, 6 797 строк.
- 5 797 клиентов размечены (`TARGET` известен), у 1 000 клиентов `TARGET` пропущен.
- Доля дефолтов среди размеченных — около 7,8%.

## Что сделано

1. Разведочный анализ (EDA): распределения, корреляции, уровень дефолта по категориям.
2. Предобработка: удаление признаков с пропусками > 60%, обработка аномалии `DAYS_EMPLOYED`, производные признаки (возраст, стаж, долговая нагрузка), импутация и One-Hot кодирование в `Pipeline`.
3. Обучение и подбор гиперпараметров (`GridSearchCV`, 5 фолдов, метрика ROC-AUC) для Random Forest и Gradient Boosting.
4. Сравнение моделей на стратифицированной holdout-выборке (20%).
5. Интерпретация: feature importance, permutation importance, partial dependence.
6. Прогноз вероятности дефолта для 1 000 клиентов без `TARGET`.

## Результаты

| Модель | ROC-AUC (CV) | ROC-AUC (holdout) | F1 (класс 1) |
|---|---|---|---|
| Random Forest | 0,7356 | 0,6643 | 0,193 |
| Gradient Boosting | **0,7653** | **0,6832** | **0,239** |

Лучшая модель — Gradient Boosting. Из-за дисбаланса классов порог классификации подобран по максимуму F1 (≈ 0,13), а не фиксирован на 0,5.

## Файлы

- `credit_scoring.ipynb` — полный ход работы и графики.
- `predictions_TARGET_1000.csv` — вероятности дефолта и итоговый прогноз для 1 000 клиентов.

## Запуск

```bash
pip install pandas numpy scikit-learn matplotlib seaborn openpyxl jupyter
jupyter notebook credit_scoring.ipynb
```

Ноутбук следует запускать из корня проекта: путь к `scoring case.xlsx` относительный. Файл прогнозов перезаписывается при выполнении последних ячеек.
